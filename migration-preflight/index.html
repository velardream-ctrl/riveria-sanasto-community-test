Сверка двух резервных копий

Только на твоём устройстве. Два JSON-файла проверяются в браузере. Ничего не отправляется в сеть, не загружается в Firebase и не восстанавливается.

Выбери две копии, скачанные на действующем сайте через «Данные → Скачать JSON», начиная с более ранней.

Файлы не выбраны.
