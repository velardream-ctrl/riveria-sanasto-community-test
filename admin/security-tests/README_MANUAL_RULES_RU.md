# Полные правила TEST Firebase — готовый вариант для копирования

**Владелец и автор проекта: Илья Дмитриев.**

[**Полный код правил для ручного копирования**](./candidates/FIRESTORE_V3_DEVELOPMENT_FULL_FOR_MANUAL_REVIEW.rules)

Только для Firebase `sanastoyhteiso-v3-development`, база `(default)`. Основан на полном тексте правил, скопированном владельцем 05.11.2026, который по содержимому соответствует историческому файлу PR #8 с `collection_set` и `sync_demo_v3`. В базовом файле все разрешения пользователей и учебного словаря сохранены побайтово. Единственное изменение — отдельный блок чтения `admin_metrics/current`.

Доступ возможен при подтверждённом email, роли `request.auth.token.admin == true` (назначенной **доверенным Firebase Admin SDK**, а НЕ самим правилом) и `sign_in_provider == 'google.com'`. Гостям, студентам, непривилегированным входам отказано; записи через клиент и list metrics запрещены. Правило НЕ создаёт документ `admin_metrics/current` и НЕ назначает роль.

**Перед тем как владелец вручную нажмёт Publish:** сохранить копию текущего ruleset, убедиться, что настройки Firebase именно TEST `sanastoyhteiso-v3-development`, что исходные правила совпадают с ранее скопированными, и что auth provider владельца Google; новый блок нельзя публиковать в `riveria-sanasto-community-test` или production. Без подтверждения серверной роли админ по-прежнему не получит доступа. Обновление TEST cloud выполнять только после отдельного явного решения владельца; GitHub Actions не запускает deploy.

`admin/security-tests/security.user-supplied.test.cjs` использует **именно этот полный файл** и проверяет исходное поведение, добавление admin metrics и совместимость с учениками. Отдельный integrity test сравнивает исходные правила с кандидатом после удаления единственного добавленного блока. Только изолированный local Firestore Emulator; никакой Firebase cloud.
